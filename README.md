## 📌 About the Project

A simple interactive shopping list application that allows users to add, manage, and track items dynamically.

The project was created to practice JavaScript fundamentals, including DOM manipulation, event handling, and working with user input.

## 🛠 Technologies

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Handling

##  Features

- Add new items to the shopping list by pressing Enter
- Prevent adding empty items
- Clear input field automatically after adding a new item
- Mark items as completed by clicking on them
- Toggle items between completed and active states
- Dynamic list updates without page reload
